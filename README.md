# Admin Dashboard

Internal moderation/administration app for the classified marketplace
platform. React + TypeScript + Vite + Tailwind CSS.

See the [root README](../README.md) for prerequisites, environment setup,
and cross-app commands, and [`docs/architecture.md`](../docs/architecture.md)
for why this is a separate app from `frontend`.

## Commands

```bash
npm run dev         # start the dev server (http://localhost:5173)
npm run build       # type-check (tsc -b) + production build
npm run typecheck   # type-check only
npm run lint        # ESLint
npm run format      # Prettier --write
npm run preview     # preview the production build locally
```
